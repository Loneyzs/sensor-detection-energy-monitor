# INA219 软件答辩核对回答

核对日期：2026-11-04。对应当前 main 的5Ω／10Ω版本，以及本次实物确认的0x399F采样配置。

## 一、对原稿三个问题的回答

### 1. 现场软硬件和控制参数

主控为MSPM0G3507，软件基于Zephyr，电源标称12V。最终演示负载已改为5Ω／50W和10Ω／50W，采样电阻为R100（0.1Ω）。当前实测功率阈值为21W，连续低于阈值30秒关闭MOSFET；P≥21W保持供电或取消本轮计时。

原稿中的680Ω、2kΩ和140mW对应历史方案，应在当前讲稿中更新为5Ω、10Ω和21W。这个21W阈值在本次INA219调试前已经确定。本次调试修改了ADC设置：由0x3E67的16次硬件平均切换为0x399F的12位、不作硬件平均；I²C地址、±320mV量程、R100阻值、电流功率换算和30秒逻辑保持原有设置。

### 2. 新模块联调进度和实测数据

新模块已完成0x40通信、配置读回、转换完成及零点检查，用户确认OLED显示恢复正常。关闭输出时，记录中196次采集全部成功，后续日志至244次仍零错误，母线电压约12.240～12.252V，所记录零点电流为0～0.2mA。这组数据反映本次短时检查，不能据此宣称长期稳定性或整机绝对精度。

两档带载电流、功率及实际断电时刻由用户继续测试，当前尚未提供可引用的完整记录。下表理论值按输入恰为12V、串联0.1Ω分流电阻、忽略开关和导线损耗计算。

### 3. 讲解顺序和讲稿修订

“寄存器换算→低功率计时→断电演示”的顺序合适。开头先用一句话介绍整体目标，再展示一个接近10Ω档的换算例题，最后结合OLED状态展示两档判定。原稿的“读数60得到6mA、72mW”数学换算正确，可作为补充小电流例题；主讲例题建议与当前安培级负载一致。

原稿需同步修改的表述：两档阻值与阈值；“两路各16次平均”改为“两路12位、不作硬件平均”；“新模块尚待联调”更新为“通信和零点已验证，带载数据待现场补充”。显示内容仍为V、I、P、R及中文状态，累计电量、蜂鸣提醒、按键调阈值属于早期方案。

## 二、当前版本的寄存器换算例题

以下为说明代码换算的假设原始数据，与主机测试一致，不作为本次带载实测数据。

设分流寄存器0x01读到11881，母线寄存器0x02读到23762（0x5CD2），Rshunt=0.1Ω。

1. 分流寄存器先按int16_t解释：Vshunt=11881×10µV=118810µV=0.118810V。
2. 母线寄存器右移3位去掉状态字段：U=(23762>>3)×4mV=11880mV=11.880V；bit1为转换完成标志CNVR。
3. 电流：I=Vshunt/Rshunt=0.118810/0.1=1.1881A=1188100µA。
4. 功率：P=U×I=11.880×1.1881=14.114628W，小于21W，因此进入低功率计时。
5. 输出接通且电流有效时，R=U/I≈9.999Ω，OLED约显示10.0Ω。

代码整数公式：I[µA]=Vshunt[µV]×1000000/Rshunt[µΩ]；P[µW]=U[mV]×I[µA]/1000。乘法采用64位中间值，避免32位溢出。反向电流保留负号。0.1mA是R100下的寄存器换算步进，准确度还受到器件误差、分流电阻误差和接线影响。

## 三、可直接使用的软件口述稿

本系统监测低压直流负载的功率，当负载连续处于低功率状态30秒时自动断开供电。主控采用MSPM0G3507，运行Zephyr，通过I²C读取INA219的分流电压和母线电压。

我们在负载回路串联0.1Ω采样电阻，利用欧姆定律把压降换算成电流，再计算电压与电流的乘积得到功率。例如分流寄存器读数11881，对应118.810mV，电流为1.1881A；如果母线电压是11.880V，功率约14.115W。

本次使用5Ω和10Ω、额定功率均为50W的电阻演示高低两档。按12V输入并计入采样电阻，两档理论功率约27.682W和14.116W，因此将分界设为21W。程序始终使用实际测得的功率比较阈值。

上电后负载默认关闭，采集有效后按下并松开底板PA30按键恢复供电。功率低于21W开始计时，连续达到30秒关闭MOSFET；计时中恢复到21W及以上，立即取消本轮计时。自动断电后保持关闭，按键可以恢复，计时期间按键可以重新计时。

OLED显示V、I、P、R和中文状态，并在独立线程刷新。采集失败会关闭负载，数据恢复后等待按键重新接通。本次联调中，我们通过原始寄存器检查发现16次硬件平均时的零点异常，改用经过实测验证的12位配置，恢复稳定采集。

## 四、现场演示步骤与追问

先展示输出关闭时的电压、电流和状态，再接10Ω并按底板PA30恢复供电，观察待机计时和30秒后断电；断电更换5Ω，恢复供电后观察功率高于21W、超过30秒继续工作。补充展示按键重新计时及恢复供电。计时以首次低功率有效采样为起点，人工按键时刻与它可能相差一个采样周期。

**为什么不用INA219的电流、功率寄存器？** 直接读分流与母线两个电压寄存器，已能在主控中计算I、P，因此当前无需写校准寄存器。分流阻值必须与实物一致；后续若做精度校准，仍需与参考仪表比较。

**为什么输出关闭后还有约12V？** MOSFET切断低边负载回路，INA219的VIN−对地电压仍可能接近电源电压。是否断电应结合输出状态和电流、功率判断。

**为什么改成12位？** 16次硬件平均下，本次模块实测零点出现0x1000、0x2000等异常值；取消硬件平均后恢复正常。这是本次模块的实测选择，12位测量足以区分相差约1.165A的两档负载。

**为什么不用瞬时低功率立刻断电？** 连续30秒条件容忍短时功率下降；期间任一有效采样恢复到阈值就取消计时。供电期间采样间隔超过500ms或采集失败时，程序转故障并关闭输出。

**为什么R有时显示“--”？** 输出关闭、采样无效、电压非正，或电流低于1mA时不计算R，避免零点附近除法放大波动。R是测量点以下回路的等效阻值，也会包含开关和导线的影响。

**能否宣称测量精度或节能率已验证？** 当前有通信、零点、主机测试和构建证据。两档带载误差、温升及整体节能率需要参考仪表和完整实验数据；报告按实际记录填写。
