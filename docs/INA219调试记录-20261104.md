# INA219 实物调试简记（2026-11-04）

本次使用 MSPM0G3507、Zephyr、12V 电源和 R100（0.1Ω）INA219 模块。程序输出保持关闭，重点验证新传感器的配置和零点。5Ω／10Ω带载电流、功率和实际断电时刻由用户继续现场观察，本文不填写尚未记录的带载数据。

| 现象 | 排查与结果 |
|---|---|
| OLED显示“传感器异常”，写配置返回-5 | SCL原接线错误，改接PB2；SDA为PB3。修正后0x40有应答。 |
| 第一块模块启用测量后配置回到0x399F，转换超时 | 关闭测量的0x3998能写入；0x3E67无法保持。用户在模块VS/GND处测得接近3.3V，供电来自编码器3接口。更换模块后配置读回正常。具体内部原因未确定。 |
| 更换后0x3E67配置正确，但零点电流出现约0.4096A、0.8192A等跳变 | 分流原始值出现0x1000、0x2000等；用单次触发冻结采样后，连续32次重复读到同一异常值。降低通信速率未消除跳变。 |
| 关闭硬件平均后恢复正常 | 母线和分流ADC均采用12位、连续转换，配置由0x3E67改为0x399F。采集计数196/196全部成功；后续日志至244/244仍零错误，电压约12.240～12.252V，所记录零点电流0～0.2mA。用户确认显示正常。 |

**最终设置：** 地址0x40；分流电阻0.1Ω；PGA±320mV；母线寄存器32V档、物理输入不超过26V；两通道12位、不作硬件平均；配置0x399F。分流寄存器仍为10µV/计数，主控按有符号值计算电流、功率，换算公式和21W／30秒控制参数保持不变。12位是ADC转换设置，0.1mA是R100下的寄存器换算步进，二者均不等于整机绝对精度。

报告可引用：本系统通过原始寄存器与零点对照定位采样异常，采用经过实物验证的12位转换配置，恢复稳定测量。硬件平均的异常表现属于本次模块实测现象，记录不足以推定所有INA219均存在该问题。

调试期间另处理过MCU停在等待调试复位状态、OLED不亮及蜂鸣器持续响：通过PWR-AP恢复CPU访问，重新烧录应用并完整校验后恢复运行；恢复过程中未执行J-Link弹窗建议的整片擦除或Factory Reset。J-Link固定VTref=3.3V是配置值，实际使用会供电的“3.3V”线保持断开，保留SWDIO、SWCLK和GND。

资料：[TI INA219数据手册](https://www.ti.com/lit/ds/symlink/ina219.pdf)、[TI MSPM0调试子系统说明](https://www.ti.com/lit/an/slaaeo5/slaaeo5.pdf)。本次原始日志及烧录前应用备份保存在本机`.local/debug-20261104-ina219/`，未纳入Git。
