# MSPM0G3507＋ACS712软件验证记录

## 版本和当前范围

- 原INA219软件保存于 `ina219-stable-20261104` 标签，对应 `ef8bb08`；此前OLED、PA30按键、MOSFET等已确认正常的硬件结论继续保留。
- 本版本位于 `feature/acs712-5a`，采用ACS712-05B／5A、12V、5Ω／10Ω两只50W电阻，21.6W分界，连续低功率30秒断电。
- 用户确认当前未连接单片机。本次只完成软件、主机模拟测试、页面预览与目标构建；ACS712及ADC的实物测量尚待接板验证。

已核对Allegro ACS712数据手册、TI MSPM0G3507数据手册、仓库核心板及底板原理图，以及本机Zephyr MSPM0 ADC驱动和设备树绑定。

| 项目 | 核对结果 |
|---|---|

| 电流输入 | PA25＝ADC0_CH2，底板P6第4脚；OUT经10kΩ/10kΩ分压，ADC节点100nF对地 |
| 总线电压 | PA22＝ADC0_CH7，底板已有R18=10kΩ、R19=1kΩ、C25=100nF电路，换算乘11 |

## 软件评估

按当前5Ω／10Ω演示需求，采集、零点标定、整数换算、显示、按键、30秒状态机和故障断电已实现，主机测试与目标构建均通过，未发现阻塞软件交付的问题。采样采用实测输入电压，ACS712使用5V下标称灵敏度；最终数值精度受ADC参考、5V供电、灵敏度误差和温漂影响，应在接板后对照万用表。

## 接板后待验证

1. 确认OUT分压实际为1:1，PA25零点约1.25V，PA22在12V输入时约1.09V；检查5V、3.3V及共地。
2. 关闭负载启动，确认零点标定成功、`ACS_DIAG`无持续错误，原始通道顺序和ADC完成正常。
3. 接5Ω验证约2.4A、28.8W、R约5Ω，保持供电超过30秒；按电阻要求安排散热。
4. 断电换10Ω再恢复，确认约1.2A、14.4W、R约10Ω，首次低功率有效采样后约30秒断电。
5. 确认带载电源稳定、MOSFET和导线满足持续电流；确认按键恢复及异常断电联动。
