# MSPM0G3507 验证记录

## 当前版本：5Ω／10Ω两档演示

项目采用MSPM0G3507核心板与MotherBoard，OLED PA1/PA0，INA219 PB2/PB3，MOSFET PB14，单按键PA30。固定12V供电，5Ω约2.353A／27.682W，10Ω约1.188A／14.116W（计入0.1Ω分流）。实测功率以21W为分界，连续低功率30秒直接断电。OLED仅保留V、I、P、R和中文状态。

软件实现、主机验证和固件构建均已完成，当前未发现阻塞软件交付的问题。新换INA219的实物测试与两档负载联调待硬件调试完成。

## 已确认的硬件情况

- 用户确认OLED、按键、MOSFET等部分此前均正常。OLED页面内容已随本次软件修改更新，生产渲染器预览已检查。
- SWD连接正常，工厂寄存器确认Flash128KB、SRAM32KB。两组GPIO I²C的开漏与输入使能配置此前已读回核对。
- 底板外部电源供电时，断开J-Link的3.3V供电线，仅保留PA19/SWDIO、PA20/SWCLK和GND，已验证可连接。本机J-Link固定VTref=3.3V，报告值属于配置值。
- 旧模块正常工作期间曾连续233次采集成功、零错误，测得12056mV、53500µA、644996µW；PA30恢复供电、MOSFET关断均完成过实物验证。这些记录对应旧版本和旧模块。
- 用户后续确认旧INA219因意外短路烧毁，现已更换新模块。新模块当前尚未完成实物测试；用户确认其余硬件能够满足5Ω／10Ω方案。

## 下次硬件调试：新INA219

1. 负载关闭时检查0x40通信、0x3E67配置和转换完成状态，母线电压应接近实际12V，电流在零点附近；确认转换无持续超时。
2. 先接10Ω与万用表对照，电流应约1.188A、功率约14.116W，低于21W，从首次低功率采样起约30秒断电。
3. 断电换5Ω后恢复，电流应约2.353A、功率约27.682W，稳定高于21W，运行超过30秒保持供电；观察分流电阻和负载温升。
4. 结合新模块确认PA30恢复和故障后的手动恢复。原有OLED、按键和MOSFET硬件验收结论保留。

新模块原理图已加入 `docs/INA219原理图.png`，分流电阻按R100（0.1Ω）配置；2512封装，用户估计额定1W或2W，本方案按至少1W使用。用户确认其余硬件满足带载要求，额定功率和带载温升仍以实物为准。硬件测试重点确认新模块的读数、温升和阈值余量。

字体与OLED预览由生产渲染器生成，见 `tests/ui-previews/screens.png`。逐线连接见 [接线表](MSPM0G3507接线表.md)。
