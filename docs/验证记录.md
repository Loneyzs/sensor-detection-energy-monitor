# MSPM0G3507 验证记录

## 当前版本：680Ω／2kΩ两档演示

项目采用MSPM0G3507核心板与MotherBoard，OLED PA1/PA0，INA219 PB2/PB3，MOSFET PB14，单按键PA30。固定12V供电，680Ω约17.65mA／0.212W，2kΩ约6mA／0.072W。实测功率以140mW为分界，连续低功率30秒直接断电。OLED仅保留V、I、P和中文状态。

软件实现、主机验证和固件构建均已完成，当前未发现阻塞软件交付的问题。新换INA219的实物测试与两档负载联调待硬件调试完成。

## 已确认的硬件情况

- 用户确认OLED、按键、MOSFET等部分此前均正常。OLED页面内容已随本次软件修改更新，生产渲染器预览已检查。
- SWD连接正常，工厂寄存器确认Flash128KB、SRAM32KB。两组GPIO I²C的开漏与输入使能配置此前已读回核对。
- 底板外部电源供电时，断开J-Link的3.3V供电线，仅保留PA19/SWDIO、PA20/SWCLK和GND，已验证可连接。本机J-Link固定VTref=3.3V，报告值属于配置值。
- 旧模块正常工作期间曾连续233次采集成功、零错误，测得12056mV、53500µA、644996µW；PA30恢复供电、MOSFET关断均完成过实物验证。这些记录对应旧版本和旧模块。
- 用户后续确认旧INA219因意外短路烧毁，现已更换新模块。新模块当前尚未完成实物测试。

## 下次硬件调试：新INA219

1. 负载关闭时检查0x40通信、0x3E67配置和转换完成状态，母线电压应接近实际12V，电流在零点附近；确认转换无持续超时。
2. 接680Ω后与万用表对照，电流应接近17.65mA、功率接近0.212W，稳定高于140mW，超过30秒仍保持供电。
3. 断电换2kΩ后恢复，电流应接近6mA、功率接近0.072W，稳定低于140mW；从首次低功率有效采样起约30秒断电，电流和功率回落至零点附近。
4. 结合新模块确认PA30恢复和故障后的手动恢复。原有OLED、按键和MOSFET硬件验收结论保留。

新模块的分流电阻按R100（0.1Ω）配置；若实物阻值不同，需要同步修改设备树。硬件测试重点确认实际读数和阈值余量。
